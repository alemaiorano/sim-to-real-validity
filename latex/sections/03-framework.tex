\section{Sim-to-Real Validity Framework}
\label{sec:framework}
A package contains variants with observed outcome rates and predicted scores
(Figure~\ref{fig:protocol}). Upworthy uses randomized traffic, although grouping distinct headlines
can combine image variants. MIND compares different articles within a subcategory. Reddit groups
reposts of the same image in the same subreddit; timing and exposure remain uncontrolled.

Within-package ranking does not establish absolute CTR calibration or a causal copy effect
in observational data.

\paragraph{Metric identity.}
For concordant and discordant pair counts $C,D$, the historical implementation used
\[
\gamma=(C-D)/(C+D),
\]
discarding pairs tied in either variable~\citep{goodman1954}. It is undefined when $C+D=0$ and
is not Kendall $\tau_b$. The corrected code separately computes
\[
\tau_b=\frac{C-D}{\sqrt{(C+D+T_x)(C+D+T_y)}},
\]
where $T_x,T_y$ count pairs tied only in the respective variable~\citep{kendall1945ties}.
Spearman uses average ranks~\citep{spearman1904}. Constant rank inputs yield undefined values.

Corrected top-1 and bottom-1 use uniform expected credit:
$|S_{\mathrm{pred}}\cap S_{\mathrm{real}}|/|S_{\mathrm{pred}}|$ for the corresponding extreme
sets. Captured lift averages observed rates across tied predicted maxima, then scales distance
from the observed minimum by the observed range. Constant outcomes make lift undefined.
Historical top-1 selected the first maximum and remains ordering-dependent.
