\section{Persona Panel, Prompt, and Reproducibility Details}
\label{sec:appendix}
\paragraph{Fixed panel.}
The ten-persona JSON is the reproducible input. Demographic inspiration~\citep{holcomb2013newsuse}
is not a deterministic recipe for recreating behavioral descriptions. The unweighted panel is
not an estimated population sample.

\paragraph{Historical first-person template.}
\begin{quote}\small
You are simulating a specific person reacting to a news headline on social media in 2014.\\
Person: \{persona description\} (age \{band\}, \{gender\}, mainly on \{platform\}, news
engagement: \{level\}).\\
Headline: \{headline\}.\\
As this exact person, how likely are you to click this headline? Respond ONLY with JSON:
\texttt{\{"click\_intent": <number between 0 and 1>\}}.
\end{quote}
The exact templates, including quotation marks and the first-person, third-person, and baseline
variants, are authoritative in the versioned collector. A prompt implementation alone does not
establish a completed experiment. The new collection also uses fixed 2014 framing for all
headlines, including those created outside that year; it is not a date-specific audience
reconstruction.

\paragraph{Coverage and checkpoints.}
Historical and new evidence use different policies. The historical diagnostic requires at least
one recorded score for every variant, with means over available observations. The new matched
experiment requires all planned scores in both arms for a primary package. Terminal failures,
request/choice indices, and exclusions are preserved. Configuration and source hashes prevent
mixing protocols. Each Azure request has one seed shared by its three returned choices; there
is no invented per-choice seed. Historical GPT requests did not send a seed.

\paragraph{Raw artifact and replay.}
The new collector appends and fsyncs a request record before dispatch and retains the exact
response bytes, status, usage, version, and parsing outcome afterward. Hash-chained journals
are synchronously mirrored. Unknown outcomes after interruption remain unknown and are not
silently regenerated. Offline analysis validates the request plan, input hashes, response hashes,
and journal chain, then reparses the same immutable snapshot whose hash identifies the report.
The replication bundle contains that snapshot, all inputs, request plans, aggregate reports,
source history, and the recovered historical GPT scalar checkpoint. Replaying saved bytes
requires no provider account and does not assert that future generations will match.
