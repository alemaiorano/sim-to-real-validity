\section{Experimental Setup}
\paragraph{Corpus.}
Upworthy rows are grouped by experiment and distinct headline, aggregating identical text.
Packages require at least two headlines and $3{,}000$ impressions per headline; sampling uncertainty
matters in online experiments~\citep{kohavi2009controlled}. The locked exploratory corpus has
\sensNVariants{} variants in \sensNPackages{} packages. In these locked inputs, headline linebreaks
were removed before grouping. One retained variant has such a linebreak in the source CSV; its
package is outside both selected cohorts. Exact locked strings define the saved experiments,
and the original manifests remain unchanged.

\paragraph{Archive allocation risk and sensitivity.}
The archive authors' 2024 report identifies a randomization-risk window from 25 June 2013
through 10 January 2014 inclusive~\citep{matias2024correction}. The preserved CSV contains creation dates but neither the documented problem flag nor a
risk indicator. Calendar-date overlap identifies \riskCorpusN{} corpus packages, \riskLegacyN{}
supplementary-screen packages and \riskSelectedN{} packages in the primary selected cohort.
These counts mark window membership, not individually proven defects. Bonferroni screening
cannot repair allocation problems.

A post-hoc offline sensitivity, specified after the primary collection, excludes an entire experiment if any row for that experiment in the preserved CSV has a
creation date that falls
in that inclusive window, using the original date string without inventing a timezone. Each
model otherwise retains its complete primary-package policy and the same recorded generations,
metrics and bootstrap procedure. Primary reports are preserved unchanged. Dates outside the
window are not a certification of valid randomization; this sensitivity is not confirmatory
or an independent replication.

\paragraph{Simultaneous winner screen.}
The primary experiment requires a unique observed maximum and compares it with every opponent using
two-sided pooled $z$ tests. For $k$ variants the comparison family contains $m=k(k-1)/2$ unordered
pairs. All winner--opponent comparisons must pass $\alpha/m$, with $\alpha=0.05$.
The screening statistic is $\min(1,m\max_{j\ne w}p_{wj})$. Bonferroni's inequality motivates the
adjustment~\citep{nistBonferroni}. The nominal bound is approximate and per package, conditional on
independent binomial observations, fixed sampling horizons, and adequate normal approximation. It is not an across-package
false-discovery guarantee or proof of a population winner. Repeated exposures and Reddit voting
further limit these assumptions. In the locked corpus \newSelectedN{} packages pass, all within
the supplementary selected set described below. A stricter screen does not demonstrate that removed packages had
false winners. The archive documents editorial stopping based on accumulating results~\citep{matiasUpworthy}.
Fixed-horizon $p$-values need not remain calibrated under that stopping policy; Bonferroni does
not repair invalid input $p$-values. The screen defines a reproducible cohort, without a verified
five-percent winner-error guarantee for these archived tests.

\paragraph{Supplementary winner screen.}
The supplementary aggregate comparisons use the observed best variant and runner-up,
comparing them using a one-sided pooled two-proportion $z$ test at $p<0.05$, selecting \legacySelectedN{} packages.
The direction was chosen from the data: even a two-arm null comparison can pass in either
direction, so the nominal one-sided threshold does not imply a five-percent false-positive rate.
Comparing only the runner-up need not separate a winner from every opponent. Outcome selection
changes the evaluation population. Packages failing a screen are not thereby unpredictable.

\paragraph{Matched-budget collection.}
We froze the protocol and its source before collection. Both Gemini 3.1 Flash-Lite and Azure GPT-4.1 score
every variant of the same \newSelectedN{}-package simultaneously screened exploratory cohort. This cohort
was selected from previously examined outcomes and is not a held-out population. The
matched-budget protocol is evaluated on this Upworthy cohort only; MIND, Reddit, other Upworthy
splits, model tiers, seeds and aggregation rules are covered by the supplementary analyses,
which do not establish prompt robustness.

Each variant is allocated three observations for each of ten fixed personas and thirty generic-reader
observations. Package and variant order is shuffled with a recorded seed; baseline/persona
requests are interleaved with randomized order within pairs. Temperature is $0.8$, JSON output
is requested, and output is limited to 64 tokens per choice. Gemini uses single-choice requests
with MINIMAL thinking. Azure uses three indexed choices per request in both arms: ten requests
per arm and variant. We match the number of retained scores within each model, not an identical
transport or inference protocol across providers. Token use and monetary cost are not equalized.
Choices in one request are not assumed
independent. Request seeds, exact prompts, responses, returned model identities, usage, and
failures are preserved. Provider aliases and best-effort seeds do not establish future replay
of generations.

The primary analysis retains a package only when every planned observation is valid in both
arms for all its variants. This also makes equal-persona and observation-weighted panel means
identical. Failures are never replaced with additional semantic draws; bounded retries address
transient transport failures only. Available-observation arm summaries are reported separately as sensitivity
analyses, with their own coverage, in the \texttt{available\_observation\_sensitivity} field of
the committed Gemini and Azure reports in \texttt{recollection/2026-10-31/}. The primary policy is stricter than the scalar-checkpoint analysis
requirement of at least one valid score per variant. Operational compatibility probes are retained
separately and excluded. An Azure prompt refusal initially triggered a global HTTP400 stop. Before comparative analysis,
a documented technical amendment classified only the confirmed content-filter refusal type as
terminal missing while allowing unrelated planned requests to continue. The blocked request is
not retried or rewritten; filtering remains active. Original journal bytes, the pause, source
versions and the amendment marker are preserved. Other permanent failures and budget stops remain
blocking. This is a response to an observed technical incident, not a preregistered amendment.
The fixed cohort closes before inspecting comparative performance;
there is no outcome-dependent stopping or choice of model after observing results.

\paragraph{Estimation and denominators.}
Primary package metrics are averaged without size weighting. The displayed means describe the recorded
packages. Bootstrap intervals summarize between-package resampling variability conditional on
the selection rule and recorded scores; interpreting them for a population of similarly selected
experiments additionally assumes that these packages are exchangeable independent units. Raw-backed reports include
$n_{\mathrm{total}},n_{\mathrm{valid}},n_{\mathrm{undefined}}$ and metric-specific package IDs.
Each paired gap uses packages valid in both arms for that metric. Empty estimates are undefined,
not zero. Primary and period-exclusion percentile bootstrap CIs use $10{,}000$ package resamples, seed $42$
\citep{efron1979bootstrap}. They condition on selection and recorded scores and omit generation,
selection, and outcome-measurement uncertainty. These are pointwise estimation intervals, not
simultaneous guarantees across metrics or models. Resampling treats experiment IDs as independent
units. The archive also records follow-up tests with shared content~\citep{matiasUpworthy};
related IDs may therefore be dependent. The intervals do not adjust for such dependence, and
their coverage as population confidence intervals is not established. Supplementary aggregate coefficient-specific valid counts
are not fully recorded; coverage totals are not those denominators.

\paragraph{Planning and robustness scope.}
We report coefficient estimates and intervals without assigning standardized effect-size
categories~\citep{cohen1988power}. The analysis does not establish prospective power for
averages of within-package coefficients or equivalence. Time-stamped preregistration of all thresholds is not established.

Supplementary reports cover three Upworthy splits, MIND~\citep{wu2020mind},
Reddit~\citep{lakkaraju2013name}, three Gemini models, seed runs, and aggregation. Prompt robustness is not evaluated by these artifacts. Reddit's manifest records many
more selected packages than the evaluated subset; its subset-selection procedure is undocumented.
