\section{Introduction}
LLM-based audience simulation offers a way to compare messages before live testing.
Demographic conditioning can approximate aspects of survey samples~\citep{argyleSiliconSampling},
but a copy-ranking system must predict measured engagement. We study this narrower question with
Upworthy headline experiments~\citep{matiasUpworthy}.

We compare a fixed ten-persona panel with a generic-reader baseline using a matched-budget
experiment on a simultaneously screened Upworthy cohort. Both model configurations allocate the
same number of scores to each arm and variant, preserve raw responses, and report distinct rank
and decision metrics with explicit denominators. The primary analysis uses uniform expected
credit for tied decisions and per-metric paired contrasts; a post-hoc period-exclusion sensitivity
examines the archive's documented randomization risk. The cohort contains previously examined
outcomes, so this is an exploratory evaluation rather than a new held-out test.

Supplementary evidence includes archived aggregate comparisons and a retrospective GPT-4.1
scalar-checkpoint diagnostic. These use different collection budgets, winner screens, and tie
rules and are reported separately. Reexporting an aggregate does not reconstruct its raw
observations; replaying historical scalars cannot validate absent response texts. The new
experiment supplies raw-backed evidence for its own protocol without retroactively validating
those archived generations or the other datasets.

We ask (RQ1) how this panel and generic baseline compare within tested packages, (RQ2) how
agreement varies with the observed outcome signal, and (RQ3) what the dataset, aggregation,
seed, and model comparisons establish. This evaluates a specified harness rather than all
persona methods or audience representativeness.
